# contact-management-system
Python CLI application to manage contacts using file handling
A simple command-line application built using Python to manage contacts.

## 🚀 Features
- Add new contact
- Display all contacts
- Delete contact

## 🛠 Technologies Used
- Python
- File Handling

## 📂 How It Works
- Stores contact details in a text file (contact.txt)
- Uses functions and loops for interaction
- Menu-driven CLI interface

## ▶️ How to Run
1. Clone the repository
2. Run contact_app.py
3. Follow on-screen instructions
